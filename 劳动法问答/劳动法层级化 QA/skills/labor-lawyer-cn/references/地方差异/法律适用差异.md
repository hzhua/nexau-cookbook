# 法律适用差异

> 竞业限制、仲裁时效、病假工资等法律适用方面的地方差异，以及地方法规查询入口。

---

## 一、竞业限制补偿金标准

### 1.1 各地标准对比

| 地区 | 最低标准 | 依据 |
|-----|---------|------|
| **北京** | 不低于离职前12个月平均工资的30%，且不低于最低工资 | 《北京市高级人民法院、北京市劳动人事争议仲裁委员会关于审理劳动争议案件解答（一）》第82条 |
| **上海** | 有约定从约定，无约定按正常工资的20%-50% | 上海司法实践 |
| **深圳** | 不低于离职前12个月平均工资的50% | 《深圳经济特区企业技术秘密保护条例》第24条 |
| **江苏** | 不低于离职前12个月平均工资的三分之一 | 江苏司法实践 |
| **浙江** | 不低于离职前12个月平均工资的30% | 浙江司法实践 |
| **广东** | 有约定从约定，但应合理 | 广东司法实践 |

### 1.2 注意事项

- 竞业限制补偿应在离职后按月支付
- 连续3个月（部分地区2个月）不支付，劳动者可要求解除竞业限制

## 二、劳动仲裁时效差异

### 2.1 一般规定

**《劳动争议调解仲裁法》第27条**：
- 仲裁时效：1年
- 从知道或应当知道权利被侵害之日起计算

### 2.2 特殊规定

**拖欠劳动报酬**：
- 劳动关系存续期间：不受1年限制
- 劳动关系终止后：应在1年内提出

**双倍工资时效（各地不同）**：

| 地区 | 时效计算方式 |
|-----|-------------|
| **北京** | 从用工满1年之日起算1年 |
| **上海** | 从用工满1年之日起算1年 |
| **广东** | 逐月计算，每月的双倍工资单独计算时效 |
| **江苏** | 从用工满1年之日起算1年 |

## 三、其他重要地方差异

### 3.1 病假工资/疾病救济费

| 地区 | 最低标准 |
|-----|---------|
| 北京 | 不低于最低工资的80% |
| 上海 | 按工龄和连续病假时间计算，最低为本人工资的60% |
| 广东 | 不低于最低工资的80% |
| 深圳 | 不低于最低工资的80% |

### 3.2 试用期工资

**国家最低标准**：不低于转正工资的80%，且不低于最低工资

**地方加强规定**：
- 部分地区要求试用期工资还应符合同工同酬原则

### 3.3 离职证明出具时间

**《劳动合同法》第50条**：应在解除或终止劳动合同时出具

**地方加强规定**：
- 部分地区规定如员工要求，应在3日内出具
- 未出具的，可能面临行政处罚

## 四、查询建议

### 4.1 查询优先级

1. **当地人社局官网** - 最权威的当地政策来源
2. **当地高级人民法院规定** - 司法实践指引
3. **当地劳动仲裁委指导意见** - 仲裁实践指引
4. **当地人大立法** - 地方性法规

### 4.2 常用查询关键词

- "XX省 劳动合同条例"
- "XX市 工资支付规定"
- "XX省 人社厅 关于劳动争议案件的指导意见"
- "XX市 高级人民法院 劳动争议案件解答"

---

## 五、地方差异查询入口

### 5.1 主要地方差异领域

| 领域 | 差异内容 |
|-----|---------|
| 最低工资标准 | 各地标准不同，每年调整 |
| 社保缴费基数 | 上下限各地不同 |
| 产假天数 | 国家规定98天，各地延长天数不同 |
| 竞业限制补偿 | 各地标准不一 |
| 高温津贴 | 标准和发放月份各地不同 |
| 经济补偿金计算 | 加班费是否计入基数，各地做法不一 |

### 5.2 地方立法查询

**省级地方性法规**：
- 各地人大官网
- 各地政府官网

**示例**：
- 《北京市劳动合同条例》
- 《上海市劳动合同条例》
- 《广东省工资支付条例》
- 《江苏省劳动合同条例》

---

**重要提示**：本文件仅汇总部分主要地方差异，具体案件处理应以当地最新规定为准。建议在提供法律建议时：

1. 询问用户所在地区
2. 查阅当地最新规定
3. 告知用户地方差异可能存在
