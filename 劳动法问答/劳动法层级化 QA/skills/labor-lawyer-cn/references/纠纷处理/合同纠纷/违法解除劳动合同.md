# 违法解除劳动合同

> 用人单位违法解除劳动合同的常见情形、法律依据、维权策略和注意事项。

---

## 1. 什么是违法解除

违法解除劳动合同是指用人单位**没有合法依据**或**未履行法定程序**就单方解除劳动合同的行为。

## 2. 常见违法情形

| 违法情形 | 说明 |
|---------|------|
| **无理由辞退** | 没有任何书面理由或口头通知就要求员工离职 |
| **末位淘汰** | 以绩效考核排名末位为由辞退员工 |
| **试用期随意辞退** | 以"不符合录用条件"为由辞退，但无明确录用条件或考核标准 |
| **违反保护期规定** | 辞退孕期、产期、哺乳期女职工，或医疗期内员工 |
| **违反程序规定** | 未提前通知工会、未书面通知劳动者等 |
| **虚构理由** | 编造"严重违纪"等理由，但无证据支持 |

## 3. 法律依据

- **《劳动合同法》第48条**：违法解除的，劳动者要求继续履行的，应当继续履行；不要求继续履行或不能继续履行的，应支付赔偿金
- **《劳动合同法》第87条**：赔偿金标准为经济补偿金的2倍

## 4. 维权策略

**第一步：保持冷静，不要签署任何文件**
- 不要签《自愿离职申请书》
- 不要签《协商一致解除协议》（除非认可补偿方案）
- 不要在空白文件上签字

**第二步：收集证据**
- 要求公司出具书面解除通知
- 保存HR或领导的辞退沟通记录（录音、微信、邮件）
- 收集劳动关系证明（合同、工资条、考勤等）

**第三步：评估选择**
| 选择 | 适用情况 | 优点 | 缺点 |
|-----|---------|------|------|
| 要求恢复劳动关系 | 希望继续工作，或赔偿金较低 | 恢复工作、补发工资 | 可能面临后续刁难 |
| 主张2N赔偿金 | 不想继续工作，或赔偿金额较高 | 一次性获得赔偿 | 需要仲裁/诉讼 |

**第四步：采取行动**
- 向公司发出《违法解除异议书》（可选但建议）
- 向劳动监察部门投诉（可选）
- 申请劳动仲裁

## 5. 注意事项

- **时效**：仲裁时效为1年，从解除之日起算
- **举证**：公司需证明解除合法，但员工需先证明存在解除事实
- **赔偿金计算**：2N中的N按离职前12个月平均工资计算
