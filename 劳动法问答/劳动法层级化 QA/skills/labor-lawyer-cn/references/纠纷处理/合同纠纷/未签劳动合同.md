# 未签劳动合同

> 未签劳动合同的法律后果、双倍工资规则、维权策略和注意事项。

---

## 1. 法律依据

- **《劳动合同法》第10条**：建立劳动关系应当订立书面劳动合同
- **《劳动合同法》第82条**：超过1个月不满1年未签合同的，支付双倍工资
- **《劳动合同法实施条例》第6、7条**：详细规定了双倍工资的起止时间和计算方法

## 2. 双倍工资规则

| 时间段 | 法律后果 |
|-------|---------|
| 用工之日起1个月内 | 无后果，宽限期 |
| 超过1个月不满1年未签 | 从满1个月次日起支付双倍工资，最多11个月 |
| 满1年未签 | 视为已订立无固定期限劳动合同，双倍工资最多11个月 |

## 3. 维权策略

**第一步：确认事实**
- 是否有书面劳动合同
- 合同是否自己签字
- 合同是否在手中

**第二步：收集证据**
证明事实劳动关系的证据：
- 工资支付记录（银行流水）
- 社保缴纳记录
- 考勤记录
- 工牌、门禁卡
- 工作邮件、工作群记录
- 入职登记表

**第三步：计算索赔金额**
```
双倍工资 = 实际月工资 × 未签合同的月数（最多11个月）
```

**第四步：采取行动**
- 向公司发出《签订劳动合同通知书》（可选）
- 申请劳动仲裁

## 4. 注意事项

- **仲裁时效**：各地做法不一，有的从满1年起算，有的按月起算，建议尽早申请
- **举证责任**：员工需证明劳动关系存在及入职时间
