# 未签劳动合同双倍工资计算

> 未签劳动合同情形下双倍工资的计算规则、起算时间、最多11个月限制及仲裁时效。

---

## 1. 适用情形

根据《劳动合同法》第82条和《实施条例》第6、7条。

## 2. 计算规则

**用工之日起超过1个月不满1年未签合同**：
```
双倍工资 = 实际月工资 × 未签合同的月数
双倍工资起算：用工之日起满1个月的次日
双倍工资截止：补签合同前一日或满1年的前一日
最多11个月
```

**用工之日起满1年未签合同**：
```
双倍工资 = 实际月工资 × 11个月（满1个月次日至满1年前一日）
并视为已订立无固定期限劳动合同
```

## 3. 注意要点

- 双倍工资中的一倍是正常工资，额外支付的是"另一倍"
- 部分地区的仲裁时效从用工满1年之日起计算，需特别注意
- 公司有证据证明是劳动者原因不签合同的，可不支付

## 4. 计算示例

**情况**：小李2024年1月1日入职，公司一直未签合同，至2024年8月15日补签

**计算**：
```
未签合同期间：2024年2月1日 - 2024年8月14日
额外支付双倍工资：7个月（2月-8月）
假设月工资8000元：
双倍工资差额 = 7 × 8000 = 56000元
```
