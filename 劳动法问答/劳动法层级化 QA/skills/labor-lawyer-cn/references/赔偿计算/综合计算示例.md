## 一、综合计算示例

### 案例：员工被违法辞退的全额索赔

**情况**：
- 工作时间：2021年3月1日 - 2024年7月15日
- 离职前12个月平均工资：10000元（含基本工资、绩效、补贴）
- 加班情况（有证据）：
  - 平日加班：共100小时
  - 周末加班：共15天（未补休）
  - 法定节假日加班：2天
- 未休年假：5天

**计算**：

1. **违法解除赔偿金（2N）**
```
工作年限：3年4个月 = 3.5年
赔偿金 = 3.5 × 10000 × 2 = 70000元
```

2. **加班费**
```
小时工资 = 10000 ÷ 174 = 57.47元
日工资 = 10000 ÷ 21.75 = 459.77元

平日加班费 = 57.47 × 100 × 150% = 8620.50元
周末加班费 = 459.77 × 15 × 200% = 13793.10元
法定节假日加班费 = 459.77 × 2 × 300% = 2758.62元

加班费合计 = 25172.22元
```

3. **未休年假工资**
```
未休年假工资 = 459.77 × 5 × 300% = 6896.55元
```

4. **总计**
```
总索赔金额 = 70000 + 25172.22 + 6896.55 = 102068.77元
```

## 二、Python 计算工具

### 快速计算公式表

```python
# Python计算函数

def calculate_compensation(years, months, monthly_salary, avg_salary_3x=None):
    """
    计算经济补偿金N
    avg_salary_3x: 当地社平工资3倍，如提供则适用双封顶
    """
    # 计算工作年限
    total_months = years * 12 + months
    if months >= 6:
        calc_years = years + 1
    elif months > 0:
        calc_years = years + 0.5
    else:
        calc_years = years

    # 双封顶处理
    if avg_salary_3x and monthly_salary > avg_salary_3x:
        calc_salary = avg_salary_3x
        calc_years = min(calc_years, 12)
    else:
        calc_salary = monthly_salary

    n = calc_years * calc_salary
    n_plus_1 = n + monthly_salary  # 代通知金按上月工资
    n_2 = n * 2

    return {
        'N': round(n, 2),
        'N+1': round(n_plus_1, 2),
        '2N': round(n_2, 2)
    }

def calculate_overtime(monthly_salary, weekday_hours=0, weekend_days=0, holiday_days=0):
    """
    计算加班费
    """
    hour_salary = monthly_salary / 174
    day_salary = monthly_salary / 21.75

    weekday_pay = hour_salary * weekday_hours * 1.5
    weekend_pay = day_salary * weekend_days * 2
    holiday_pay = day_salary * holiday_days * 3

    return {
        '平日加班费': round(weekday_pay, 2),
        '周末加班费': round(weekend_pay, 2),
        '法定节假日加班费': round(holiday_pay, 2),
        '合计': round(weekday_pay + weekend_pay + holiday_pay, 2)
    }

def calculate_annual_leave_pay(monthly_salary, unused_days):
    """
    计算未休年假工资
    """
    day_salary = monthly_salary / 21.75
    return round(day_salary * unused_days * 3, 2)
```
