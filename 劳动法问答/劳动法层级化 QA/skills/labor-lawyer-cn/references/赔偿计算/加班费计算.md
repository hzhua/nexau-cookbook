# 加班费计算

> 工作日、休息日、法定节假日三档加班费的计算标准、公式和示例。

---

## 1. 计算标准

**《劳动法》第44条**：

| 加班类型 | 计算标准 |
|---------|---------|
| 工作日延长（平日加班） | 小时工资 × 150% |
| 休息日加班（周末） | 日工资 × 200%（可安排补休） |
| 法定节假日加班 | 日工资 × 300%（不可补休） |

## 2. 计算基数

**日工资和小时工资换算**：
```
日工资 = 月工资 ÷ 21.75
小时工资 = 日工资 ÷ 8 = 月工资 ÷ 174
```

**注**：21.75是月计薪天数，计算方式为：(365天 - 104天休息日) ÷ 12个月 = 21.75天

## 3. 计算公式

```
工作日加班费 = 小时工资 × 加班小时数 × 150%
休息日加班费 = 日工资 × 加班天数 × 200%
法定节假日加班费 = 日工资 × 加班天数 × 300%
```

## 4. 法定节假日清单（2025年）

| 节日 | 放假天数 | 日期 |
|------|---------|------|
| 元旦 | 1天 | 1月1日 |
| 春节 | 4天 | 除夕、农历正月初一至初三 |
| 清明节 | 1天 | 清明当日 |
| 劳动节 | 2天 | 5月1日、2日 |
| 端午节 | 1天 | 端午当日 |
| 中秋节 | 1天 | 中秋当日 |
| 国庆节 | 3天 | 10月1日至3日 |

## 5. 计算示例

### 示例1：平日加班

**情况**：小张月工资8700元，某月工作日加班共20小时

**计算**：
```
小时工资 = 8700 ÷ 174 = 50元/小时
平日加班费 = 50 × 20 × 150% = 1500元
```

### 示例2：休息日加班

**情况**：小李月工资6525元，某月周末加班2天（每天8小时），公司未安排补休

**计算**：
```
日工资 = 6525 ÷ 21.75 = 300元/天
休息日加班费 = 300 × 2 × 200% = 1200元
```

### 示例3：法定节假日加班

**情况**：小王月工资8700元，春节法定假日加班3天

**计算**：
```
日工资 = 8700 ÷ 21.75 = 400元/天
法定节假日加班费 = 400 × 3 × 300% = 3600元
```

### 示例4：综合计算

**情况**：小陈月工资6960元，某月加班情况如下：
- 工作日延长加班：15小时
- 周末加班：1天（未补休）
- 法定节假日加班：1天

**计算**：
```
小时工资 = 6960 ÷ 174 = 40元/小时
日工资 = 6960 ÷ 21.75 = 320元/天

平日加班费 = 40 × 15 × 150% = 900元
周末加班费 = 320 × 1 × 200% = 640元
法定节假日加班费 = 320 × 1 × 300% = 960元

合计加班费 = 900 + 640 + 960 = 2500元
```
