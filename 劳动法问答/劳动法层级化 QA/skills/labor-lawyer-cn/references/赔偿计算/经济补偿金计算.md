# 经济补偿金计算（N / N+1 / 2N）

> 经济补偿金（N）、代通知金（+1）、违法解除赔偿金（2N）三者的计算规则、公式和示例。

---

## 一、经济补偿金（N）计算

### 1. 适用情形

根据《劳动合同法》第46条，以下情形应当支付经济补偿金：

| 情形 | 法律依据 |
|------|----------|
| 用人单位提出协商解除 | 第36条 |
| 劳动者因用人单位过错解除（欠薪、未缴社保等） | 第38条 |
| 用人单位无过失性解除（不胜任、医疗期满、客观情况变化） | 第40条 |
| 经济性裁员 | 第41条 |
| 劳动合同期满，用人单位不续签 | 第44条第（一）项 |
| 用人单位破产、关闭、解散 | 第44条第（四）（五）项 |

### 2. 计算公式

```
经济补偿金 = 工作年限 × 月工资
```

### 3. 工作年限计算规则

**《劳动合同法》第47条规定**：
- 每满1年支付1个月工资
- 6个月以上不满1年的，按1年计算
- 不满6个月的，支付0.5个月工资

**示例**：
| 实际工作年限 | 计算年限 |
|-------------|---------|
| 2年3个月 | 2.5年 |
| 2年6个月 | 3年 |
| 2年7个月 | 3年 |
| 3年整 | 3年 |

### 4. 月工资计算规则

**《劳动合同法》第47条第3款**：
> 月工资是指劳动者在劳动合同解除或者终止前十二个月的平均工资。

**《劳动合同法实施条例》第27条**：
> 月工资按照劳动者应得工资计算，包括计时工资或者计件工资以及奖金、津贴和补贴等货币性收入。

**包含项目**：
- 基本工资
- 岗位工资
- 绩效工资/奖金
- 各类津贴补贴（交通、通讯、餐补等）
- 加班费（注：部分地区不计入，需查当地规定）

**不包含项目**：
- 社保和公积金个人缴纳部分（应得工资为扣除前）
- 年终奖（应分摊到对应月份）

### 5. 高薪员工的双封顶

**《劳动合同法》第47条第2款**：

如果劳动者月工资高于用人单位所在直辖市、设区的市级人民政府公布的本地区上年度职工月平均工资**3倍**的：
- 补偿标准按社平工资**3倍**计算
- 补偿年限最高不超过**12年**

**计算公式**：
```
封顶经济补偿金 = min(实际月工资, 社平工资×3) × min(工作年限, 12)
```

### 6. 计算示例

#### 示例1：普通员工

**情况**：小王工作3年7个月，离职前12个月平均工资8000元

**计算**：
```
工作年限：3年7个月 = 4年（6个月以上按1年计）
月工资：8000元
经济补偿金 = 4 × 8000 = 32000元
```

#### 示例2：高薪员工

**情况**：老李工作15年，月平均工资50000元，当地上年度社平工资12000元

**计算**：
```
社平工资3倍 = 12000 × 3 = 36000元
实际月工资50000元 > 36000元，按36000元计算
工作年限15年 > 12年封顶，按12年计算

经济补偿金 = 12 × 36000 = 432000元
```

#### 示例3：工作不满12个月

**情况**：小张工作8个月，月平均工资6000元

**计算**：
```
《劳动合同法实施条例》第27条：劳动者工作不满12个月的，按照实际工作的月数计算平均工资。

工作年限：8个月 = 1年（6个月以上按1年计）
经济补偿金 = 1 × 6000 = 6000元
```

## 二、代通知金（+1）计算

### 1. 适用情形

根据《劳动合同法》第40条，用人单位无过失性解除但未提前30日书面通知的，需额外支付1个月工资。

### 2. 计算标准

**《劳动合同法实施条例》第20条**：
> 额外支付的工资应当按照该劳动者上一个月的工资标准确定。

**注意**：这里的"上一个月工资"是指劳动者正常出勤情况下的全额工资，不是平均工资。

### 3. 计算示例

**情况**：公司因客观情况变化解除合同，未提前30日通知，员工上一个月工资10000元

**计算**：
```
代通知金 = 上一个月工资 = 10000元
```

## 三、违法解除赔偿金（2N）计算

### 1. 适用情形

根据《劳动合同法》第87条，用人单位违法解除劳动合同的，应当支付赔偿金。

**常见违法解除情形**：
- 无理由辞退
- 以末位淘汰为由辞退
- 试用期随意辞退（不符合第39条第（一）项条件）
- 辞退孕期、产期、哺乳期女职工（第42条）
- 辞退医疗期内员工（第42条）
- 辞退工伤丧失劳动能力员工（第42条）

### 2. 计算公式

```
赔偿金 = 经济补偿金 × 2 = 工作年限 × 月工资 × 2
```

### 3. 注意要点

**《劳动合同法实施条例》第25条**：
> 用人单位违反劳动合同法的规定解除或者终止劳动合同，依照劳动合同法第八十七条的规定支付了赔偿金的，不再支付经济补偿。

**即**：2N和N不可同时主张，选择适用。

### 4. 计算示例

#### 示例1：违法解除

**情况**：小陈工作2年3个月，月平均工资7000元，被无理由辞退

**计算**：
```
工作年限：2年3个月 = 2.5年
经济补偿金（N）= 2.5 × 7000 = 17500元
违法解除赔偿金（2N）= 17500 × 2 = 35000元
```

#### 示例2：孕期被辞退

**情况**：怀孕5个月的女员工，工作4年，月平均工资9000元，被公司辞退

**计算**：
```
孕期属于第42条保护期，辞退属于违法解除
工作年限：4年
赔偿金（2N）= 4 × 9000 × 2 = 72000元

同时可主张：
- 恢复劳动关系（如希望继续工作）
- 孕期、产期、哺乳期工资损失
```
