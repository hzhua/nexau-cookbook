# 未休年假工资计算

> 未休年假工资的计算标准、年假天数对应工作年限，以及300%补偿规则。

---

## 1. 计算标准

**《职工带薪年休假条例》第5条**：
> 对职工应休未休的年休假天数，单位应当按照该职工日工资收入的300%支付年休假工资报酬。

## 2. 计算规则

```
未休年假工资 = 日工资 × 未休天数 × 300%

注意：其中100%为正常工资，额外支付200%
```

## 3. 年假天数

| 累计工作年限 | 年假天数 |
|-------------|---------|
| 满1年不满10年 | 5天 |
| 满10年不满20年 | 10天 |
| 满20年 | 15天 |

## 4. 计算示例

**情况**：员工累计工作6年，当年应休年假5天，因公司原因未安排休假，日工资400元

**计算**：
```
未休年假工资 = 400 × 5 × 300% = 6000元

（其中2000元为正常工资已发，额外应支付4000元）
```
