# 赔偿计算

各类劳动赔偿金额的计算公式、规则和示例。

## 本级文件

- `经济补偿金计算.md` — N/N+1/2N 计算规则：经济补偿金（工作年限×月工资）、代通知金（+1个月工资）、违法解除赔偿金（2N），含月工资计算基数、双封顶规则、不可并用规则
- `加班费计算.md` — 工作日150%、休息日200%、法定节假日300%三档计算标准，日工资=月工资÷21.75
- `双倍工资计算.md` — 未签劳动合同双倍工资，起算时间（满1月次日）、最多11个月、仲裁时效
- `年假工资计算.md` — 未休年假按日工资×300%补偿，年假天数（5/10/15天）对应工作年限
- `综合计算示例.md` — 完整案例串联多项赔偿计算 + Python 计算工具代码
