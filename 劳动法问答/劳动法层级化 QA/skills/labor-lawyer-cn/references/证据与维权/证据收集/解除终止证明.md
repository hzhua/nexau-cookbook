# 解除终止证明

> 证明被辞退或合同终止的证据，包括录音技巧指引。

---

## 一、辞退证据

**核心证据**：
- [ ] 解除劳动合同通知书（书面，盖公章）
- [ ] 辞退通知邮件
- [ ] 辞退微信/短信记录
- [ ] 与HR/领导沟通辞退的录音

### 录音要点

- 明确对方身份（称呼对方职位+姓名）
- 明确谈话主题（"请问公司是要辞退我吗？"）
- 明确辞退理由（"请问辞退我的原因是什么？"）
- 明确补偿方案（"公司给多少补偿？"）

### 录音合法性

- 双方谈话录音，不违反法律禁止性规定
- 录音可作为证据使用

## 二、被迫解除证据

如果是因公司违法（欠薪、未缴社保等）被迫解除：

- [ ] 证明公司违法行为的证据（欠薪记录、社保未缴记录）
- [ ] 《被迫解除劳动合同通知书》及送达证据
- [ ] 快递单据（EMS优先，备注文件名称）
- [ ] 签收记录

## 三、离职交接证据

- [ ] 离职交接单
- [ ] 工作交接清单
- [ ] 离职证明（盖公章）

**注意**：离职证明上如有"个人原因离职"等字样，如有异议应及时提出。
