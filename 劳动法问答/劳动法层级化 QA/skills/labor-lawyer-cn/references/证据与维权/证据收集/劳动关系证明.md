# 劳动关系证明

> 证明劳动关系存在及入职时间的核心证据，是劳动维权的基础。

---

## 一、书面劳动合同

**证明目的**：最直接的劳动关系证明

**收集要点**：
- [ ] 劳动合同原件（必备）
- [ ] 注意合同中的岗位、薪资、工作地点条款
- [ ] 注意合同期限和试用期约定
- [ ] 如有补充协议、变更协议一并收集

**常见问题**：
- 公司不给合同原件 → 可向劳动监察投诉
- 合同空白处未填写 → 拍照留存，及时要求补填
- 签了合同但公司没盖章 → 保留自己的签字页

## 二、工资支付记录

**证明目的**：证明存在劳动关系、工资标准、工作年限

**收集要点**：
- [ ] 银行工资流水（去银行打印，盖银行章）
- [ ] 工资条（纸质或电子版）
- [ ] 个税APP缴纳记录截图
- [ ] 年终奖、季度奖发放记录

**注意事项**：
- 银行流水要显示对方账户名称（公司名称）
- 现金发放工资的，要求公司出具收据或签字确认
- 私人账户转账发工资的，注意备注内容

## 三、社保和公积金记录

**证明目的**：证明劳动关系存续时间

**收集方式**：
- [ ] 社保缴纳记录（社保局官网/APP下载或窗口打印）
- [ ] 公积金缴纳记录（公积金管理中心打印）
- [ ] 医保卡消费记录

## 四、入职和在职材料

**收集要点**：
- [ ] 录用通知书/offer letter
- [ ] 入职登记表
- [ ] 员工手册签收记录
- [ ] 培训记录
- [ ] 绩效考核表
- [ ] 岗位任命文件

## 五、身份识别物品

**收集要点**：
- [ ] 工牌、工作证
- [ ] 门禁卡
- [ ] 名片
- [ ] 公司邮箱账号
- [ ] 公司内部系统账号

## 六、工作痕迹证据

**收集要点**：
- [ ] 工作邮件（导出保存）
- [ ] 工作群聊天记录（截图+保留原始记录）
- [ ] 工作成果文件（报告、方案、代码等）
- [ ] 客户往来记录
- [ ] 报销单据
