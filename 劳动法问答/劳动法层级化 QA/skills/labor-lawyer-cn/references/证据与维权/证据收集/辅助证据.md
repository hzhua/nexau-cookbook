# 辅助证据

> 补充性证据材料，配合核心证据形成完整证据链。本文同时提供证据类型总览分类表。

---

## 一、证据类型总览

### 1.1 证据的重要性

在劳动争议中，**证据是决定胜负的关键**。劳动仲裁和诉讼遵循"谁主张，谁举证"原则，没有证据支撑的主张很难获得支持。

### 1.2 证据分类

| 类别 | 证明目的 |
|-----|---------|
| 劳动关系证明 | 证明存在劳动关系及入职时间 |
| 工资收入证明 | 证明工资标准，用于计算补偿金 |
| 工作时间证明 | 证明加班事实、工作年限 |
| 解除/终止证明 | 证明被辞退或合同终止 |
| 其他辅助证据 | 辅助证明违法事实 |

> 各类证据的详细收集要点见本目录下对应文件。
