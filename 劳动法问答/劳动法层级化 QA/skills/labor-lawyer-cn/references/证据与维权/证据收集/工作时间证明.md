# 工作时间证明

> 证明加班事实、出勤情况和工作年限的证据。

---

## 一、考勤记录

**证明目的**：证明加班事实、出勤情况

**收集要点**：
- [ ] 考勤打卡记录（导出电子版或拍照）
- [ ] 考勤统计表（如有）
- [ ] 请假单、调休单
- [ ] 出差审批单

**注意事项**：
- 很多公司使用钉钉、企业微信等系统，离职前务必导出记录
- 拍照时要显示完整的时间信息
- 保留原始记录，不要只依赖截图

## 二、加班证据

**直接证据**：
- [ ] 加班审批单/加班申请记录
- [ ] 考勤记录显示的加班时间
- [ ] 工作群加班通知
- [ ] 加班期间的工作邮件（时间戳）

**间接证据**：
- [ ] 加班餐费报销记录
- [ ] 下班时间打车报销记录
- [ ] 工作成果交付时间（晚于下班时间）
- [ ] 同事证言

## 三、年休假证据

**收集要点**：
- [ ] 累计工作年限证明（前单位社保记录、离职证明）
- [ ] 公司年假制度
- [ ] 年假申请记录
- [ ] 未休年假天数确认
