# 仲裁流程指引

> 劳动仲裁完整流程、管辖规则、申请材料清单、时效和费用说明。

---

## 一、仲裁流程

```
申请仲裁 → 立案受理（5日内）→ 开庭审理 → 裁决（45日内，可延长15日）
```

## 二、申请准备

### 2.1 管辖

用人单位所在地或劳动合同履行地的劳动人事争议仲裁委员会。

### 2.2 申请材料

1. 仲裁申请书（3份）
2. 身份证复印件
3. 证据材料及证据清单
4. 用人单位工商信息（国家企业信用信息公示系统打印）

## 三、仲裁时效

- 一般争议：**1年**（从知道或应当知道权利被侵害之日起）
- 拖欠劳动报酬：劳动关系存续期间不受1年限制，但终止后应在1年内提出

## 四、费用

劳动仲裁**不收费**。
