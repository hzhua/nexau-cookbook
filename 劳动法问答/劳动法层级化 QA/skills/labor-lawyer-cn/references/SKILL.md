# 劳动法知识库

中国劳动法领域的完整知识体系，涵盖法律条文、赔偿计算、纠纷处理、证据维权和地方差异五大板块。

## 子目录

- `法律条文/` — 7 部核心法律法规原文：劳动法、劳动合同法及实施条例、年休假条例、工伤保险条例、社会保险法、劳动争议调解仲裁法（按合同用工/保障保险/争议解决分类）
- `赔偿计算/` — 各类赔偿金额的计算公式和规则：经济补偿金 N/N+1/2N、加班费三档计算、未签合同双倍工资、未休年假300%工资、综合计算示例与 Python 工具（5 件）
- `纠纷处理/` — 8 类常见劳动纠纷处理指南：违法解除、未签合同、竞业限制、加班费争议、欠薪、社保、工伤、女职工保护（按合同纠纷/待遇纠纷/特殊情形分类）
- `证据与维权/` — 证据收集清单（6 类证据类型）+ 维权程序（仲裁流程、取证技巧、证据提交）
- `地方差异/` — 各省市执行标准差异速查（薪酬/假期/法律适用）+ 官方权威信息来源和查询渠道
